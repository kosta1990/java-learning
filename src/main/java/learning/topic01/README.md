# Тема 1: main, print и println

Цель: запускать простую программу и понимать вывод текста.

- [Практика](practice/Practice01.java)
- [Домашнее задание](homework/README.md)

Метод `main` — точка начала выполнения программы. Команды внутри выполняются по порядку.
`print` выводит текст без перехода на новую строку, `println` после вывода переводит курсор на следующую строку.

В Java 25 допустим метод `void main()` без `public static` и без параметров. В этом Maven-проекте упражнения размещены в именованных пакетах, поэтому здесь используем явное объявление класса. Подробнее классы и пакеты разберём по мере курса.
