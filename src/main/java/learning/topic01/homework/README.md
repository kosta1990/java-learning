# Домашнее задание 1

Создайте в этой папке Java-класс `Homework01` через IntelliJ IDEA.
Используйте метод `void main()` и команды `System.out.print` и `System.out.println`.

Получите такой вывод:

```text
Test: Login
Status: passed
```

Условия:
1. Первую строку соберите двумя командами: отдельно текст `Test: ` и `Login`.
2. Вторую строку выведите одной командой.
3. Перед запуском предскажите вывод, затем сравните его с результатом.
4. Объясните своими словами, почему первая строка собирается из двух команд.

Пришлите свой код ментору для проверки, затем сохраните решение отдельным коммитом.
