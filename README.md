# Java для автоматизации тестирования

Учебный проект на Java 25. Каждая тема хранится отдельно в `src/main/java/learning/topicNN`.

## Темы

- [Тема 1: main, print и println](src/main/java/learning/topic01/README.md)

Внутри каждой темы:
- `practice` — примеры и практические упражнения;
- `homework` — условие ДЗ и собственное решение.

Каждое выполненное ДЗ сохраняется отдельным коммитом, например: `Тема 1: ДЗ по print и println`. Исправления можно сохранять следующим коммитом.

## Запуск в IntelliJ IDEA

Выберите JDK 25. Откройте Java-файл упражнения и нажмите кнопку запуска рядом с методом `main`.

Начальный файл `org/example/Main.java` — пример, созданный IDEA.
